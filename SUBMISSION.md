# Submission Guide

All submissions must be completed through the [official application form](https://forms.gle/fwNQ8dKRGE6g5jJs5).

You will be required to provide:

- GitHub repository link of your solution
- Setup and run instructions
- Short technical reflection answers

Make sure your repository is publicly accessible.

## Evaluation Rubric

1. Functionality – 30% 

   * Does the application work as expected?
2. Code Quality – 25%

   * Is the code clean, readable, and maintainable?
3. Architecture – 20%

   * Is the project organized and scalable?
4. Documentation – 10%

   * Are setup instructions and documentation clear?
5. Error Handling & Validation – 10%

   * Are edge cases and validation handled appropriately?
6. Communication – 5%

   * Does the candidate clearly explain technical decisions?
